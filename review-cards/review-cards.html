CSS Review Cards

Hover over each card to reveal the answer.

What does scaleX(2) do?

It makes an element twice as wide.

What does rotate() do?

It rotates an element by a number of degrees.

What does translate() do?

It moves an element from its original position.

What does transition-duration control?

It controls how long a transition takes to complete.

What does transition-delay do?

It delays the start of a transition.

What does a linear timing function do?

It keeps the transition speed consistent throughout.

What does animation-iteration-count: infinite do?

It makes an animation repeat endlessly.

What does animation-direction: alternate do?

It switches between forward and backward each loop.

What does animation-fill-mode: forwards do?

It keeps the ending styles after the animation finishes.
