CHECKMATE SOCIETY - BASIC WEB DESIGN FINAL PROJECT

Created by: Ruzgar Savas
Location: Istanbul, Türkiye
Founded: 2025

Pages:
- index.html - Home + coded standard chessboard
- about.html - Club information + centered club visual
- learn.html - Interactive piece guide + nested list
- events.html - Complex event table + event visual
- resources.html - External resources + legal knight-move CSS animation
- join.html - Accessible membership form

Design notes:
- One external stylesheet: css/styles.css
- No JavaScript is used. Piece interaction uses HTML details/summary and CSS.
- Flexbox, CSS Grid, transitions, animation, media queries, lists, a complex table, and a form are included.
- Chess movement text was checked against official US Chess/FIDE rules.
- Visuals are coded with HTML/CSS and standard chess symbols, so no outside photographs are required.
- Accessibility features include semantic headings, a skip link, keyboard-friendly details elements, descriptive links, labels, captions, strong contrast, and animation description text.
