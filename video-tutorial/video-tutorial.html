How to Embed a YouTube Video

This tutorial explains how to embed a YouTube video into a web page.

Step 1: Open the Share Menu

Open the YouTube video you want to use. Click the Share button underneath the video.

Step 2: Choose Embed

In the Share window, select the Embed option. This will open the HTML code used to display the video.

Step 3: Copy the Embed Code

YouTube will create an iframe code for the video. Click Copy to copy the complete embed code.

Step 4: Paste the Code Into HTML

Paste the iframe code inside the body section of your HTML page. Save the file and open it in a browser to make sure the video works.
